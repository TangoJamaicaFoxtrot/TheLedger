# Making The Ledger a lived-in record

The useful loop is: choose something → engage with it → capture an observation → develop a thought → return to it. This pass makes that loop work for books, while preserving the calm, self-directed character of the project.

Implemented: personal book entry/editing; searchable shelves; per-book notebooks; quotations/questions with locations; reading progress and personal ratings; linked and editable journal reflections; direct curriculum-to-library actions; a study that reflects current reading; validated backups and restoration.

The next priorities, in order:

1. **Private, durable storage across devices.** Authentication, per-user database permissions, reliable backups and clear save/sync feedback. This matters more than extra dashboard statistics because the value is in the writing. Browser records need an explicit migration path, with export and verification before cloud writes.
2. **Personal expeditions and resources.** Let a question become a small learning project with a purpose, selected books/articles/courses, working notes and a final synthesis. Personal sources should be visibly distinct from the curated catalogue and use the same search and linking patterns.
3. **Return to good ideas.** A quiet review shelf of open questions, saved passages and unfinished reflections. Pin what deserves attention; avoid arbitrary streaks or automated reminders by default.
4. **A useful intellectual map.** Link reflections, books, skills and disciplines to one another. Begin with explicit links and tags before adding automated connections or AI summaries that might dilute the user's own thinking.
5. **Easier capture.** Optional ISBN/title lookup with editable metadata, import formats and a reading-session log if time tracking proves useful. Keep manual entry first-class and never require a catalogue match.

Do not turn self-education into a compulsory checklist. Progress should describe what happened; it should not award understanding based on page counts or button clicks.
